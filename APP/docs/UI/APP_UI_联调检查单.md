# APP UI 联调检查单

## 1. 文档目的
用于在真实硬件上对 `APP` OLED UI 做联调与回归自检，覆盖：
- 状态流：上电、启动、自检、工作、息屏、关机、升级、错误覆盖。
- 页面流：`HOME / ENV / ACT / ALARM / SETTING / QUICK / UPGRADE / CLOSING / SLEEP / ERROR`。
- 交互流：翻页、快捷层、设置编辑/保存、告警消音、唤醒拦截。
- 异常流：普通告警、严重错误、错误恢复返回、升级锁屏。

适用版本：2026-05-01 当前实现。

## 2. 使用前提
- 工程范围：仅 `APP`，不覆盖 `BOOT` 业务 UI。
- 屏幕：`128x64` 单色 OLED，`u8g2` 路径已接通。
- 按键：`Enter / Left / Up / Down / Right` 五键可正常识别长按/短按。
- 建议联调环境：
  - 可读取当前水温、环境温度、光照、12V 状态。
  - 可观察灯光、氧泵、水泵、加热模块动作反馈。
  - 可触发普通告警与严重错误至少各 1 条。
  - 可进入升级流程或具备升级模拟入口。

## 13. 当前已知限制
- 当前主机已安装项目要求的 `AC5/armcc`，且已验证编译链可进入真实编译阶段；但 `unify_builder` 与 `UV4 -b` 均提示 `C9555E: Failed to check out a license`，当前命令行会话未取得 AC5 许可证，因此本检查单可用于实机联调记录，但“真实构建 + 发布前最终回归”仍受许可证链路阻塞。
