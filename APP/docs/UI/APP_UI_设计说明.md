# APP UI 设计说明

## 1. 设计范围
- 仅覆盖 `APP` 工程的 OLED UI。
- `BOOT` 不设计业务 UI，仅保留升级/跳转相关最小提示能力。
- 本方案面向 **SH1106/SSD1106 128x64 单色 OLED + 5 按键**。

## 2. 已确认的实现边界
- 屏幕：128x64，单色，SPI，当前驱动已切到 `u8g2` 路径。
- 刷新周期：工作显示推荐按 `boardDISP_REFRESH_TMIE = 250ms` 节奏刷新。
- 按键：`Enter / Left / Up / Down / Right` 五键。
- 当前显示任务状态：`INIT / CLOSING / SHUT_DOWN / ERR / BOOTING / WORK / UPDATA / ENG`。
- 当前 `WORK` 画面仍是测试页，说明可以直接按本方案替换为正式 UI。
- 当前板级已启用的业务模块主要有：显示、ADC、按键、蜂鸣器、照明、热管理、氧气泵、水泵、光照传感器、水温 NTC、12V 控制。
- 当前板级未启用：`DC / USB / ENG_MODE`，因此正式 UI 先聚焦养鱼罐核心模块。

## 3. UI 设计目标
1. **开机即可看懂**：用户上电后 3 秒内能看清设备状态、温度、灯光、泵类运行状态。
2. **少按键也能高效操作**：所有高频操作不超过 3 次按键。
3. **单色屏也有层次**：通过“状态栏 / 主内容区 / 底部软键提示”形成稳定认知。
4. **与代码结构匹配**：页面直接映射 `DS_BOOTING / DS_WORK / DS_ERR / DS_UPDATA_MODE` 等状态机。
5. **便于大模型和工程协作**：页面、区块、触发规则全部表格化，后续可直接转换为枚举、结构体和绘制函数。

## 4. 屏幕分区规范（统一模板）
- `顶部状态栏 8px`：设备状态、通信/传感器状态、时间/倒计时、告警角标。
- `主体内容区 40px`：当前页面核心数值或控制项。
- `底部软键区 16px`：显示当前按键语义，如“返回/确认/设置”。
- 推荐使用：
  - 6x8 字体：状态栏、辅助标签。
  - 8x16 或 12x16 字体：核心数值。
  - 图标：灯光、加热、风扇、氧泵、水泵、告警、升级。

### 4.1 实机显示文案收敛
- 真实 OLED 上屏文案统一使用短 ASCII 缩写，避免中文字库、编码和宽度不可控。
- 底栏固定优先使用：`TAB- / QUICK / TAB+`、`EXIT / APPLY / NEXT`、`TAB- / EDIT / SAVE`。
- 常用字段缩写：`WTMP` 水温、`TG` 目标温度、`AMB` 环温、`LUX/ADC` 光照、`O2` 氧泵、`WP` 水泵、`HT` 加热、`ALM` 告警、`UPD` 升级。
- `SAVE` 表示 `Right Long` 保存，不表示 `Right Short`；联调时需要单独验证长按语义。

## 5. 页面架构
### 5.1 一级状态页（与系统状态机绑定）
- `P00_INIT`：初始化页
- `P01_BOOTING`：开机自检页
- `P10_HOME`：工作首页
- `P11_ENV`：环境详情页
- `P12_ACT`：执行器控制页
- `P13_ALARM`：告警/异常页
- `P14_SETTING`：设置页
- `P20_UPGRADE`：升级页
- `P21_CLOSING`：关机中页
- `P22_SLEEP`：息屏页
- `P23_ERROR`：系统错误页

### 5.2 推荐默认流程
- 上电 -> `P00_INIT` -> `P01_BOOTING` -> `P10_HOME`
- 工作中 `Left/Right` 切换 `HOME / ENV / ACT / ALARM / SETTING`
- 任意工作页检测到严重告警 -> 覆盖弹出 `P23_ERROR`
- 长按 `Enter` -> 关机流程 `P21_CLOSING` -> `P22_SLEEP`

## 6. 按键运行细则（建议版）
### 6.1 全局规则
- **任意短按唤醒**：当息屏时，任意短按只负责亮屏，不执行功能。
- **Enter 长按**：保留现有系统开关机逻辑，不挪作它用。
- **错误优先**：严重错误页优先级高于普通工作页。
- **2 分钟无操作**：按当前配置，工作态无操作进入息屏。

### 6.2 工作页按键语义
- `Left Short`：切到上一个一级页面。
- `Right Short`：切到下一个一级页面。
- `Up Short`：列表上移 / 数值增加 / 切换上一个选项。
- `Down Short`：列表下移 / 数值减少 / 切换下一个选项。
- `Enter Short`：进入 / 确认 / 打开快捷控制。
- `Left Long`：返回首页 `P10_HOME`。
- `Right Long`：在 `HOME / ENV / ACT / ALARM` 页进入快捷控制弹层。
- `Enter Long`：系统开关机。

> 说明：这套语义兼容 5 键结构，且不会破坏现有“长按 Enter 开关机”的底层逻辑。

### 6.3 当前实现补充规则（2026-05-01）
- `QUICK` 弹层使用 `Up/Down` 切换对象，`Right Short` 也可切到下一个对象；`Enter Short` 执行当前对象。
- `QUICK` 弹层支持 `Left Short / Left Long / Right Long` 退出，并返回来源工作页。
- `SETTING` 页使用 `Enter Short` 进入/退出编辑态，使用 `Right Long` 执行保存。
- `ALARM` 页使用 `Enter Short` 执行蜂鸣器静音/恢复，不单独跳转确认页。
- 严重错误解除后，优先返回来源工作页；若来源页无效，则回 `HOME`。

## 7. 各页面定位
### P10_HOME 工作首页
用于“抬手即看”：
- 水温 / 目标温度
- 灯光亮度或模式
- 氧泵、水泵、风扇、加热状态
- 当前是否告警

### P11_ENV 环境详情
用于“看数值”：
- 水温、环境温度、光照值、12V 输入状态
- 目标温度、温控模式、最近一次刷新时间

### P12_ACT 执行器控制
用于“做控制”：
- 灯光开关 / 亮度 / 模式
- 氧泵开关
- 水泵开关
- 加热开关 / 加热策略

### P13_ALARM 告警页
用于“看风险”：
- 当前告警代码
- 当前告警说明
- 建议动作（如检查水温传感器/检查水泵）

### P14_SETTING 设置页
用于“改参数”：
- 息屏时间
- 蜂鸣器开关
- 亮度高/低档
- 恢复默认值

### P20_UPGRADE 升级页
用于“显示升级进行中”：
- 当前阶段（接收 / 校验 / 写入 / 完成）
- 百分比
- 禁止断电提示

## 8. 数据刷新策略
- 状态栏：`250ms` 周期检查，数据变化才重绘。
- 主内容区：
  - 数值页：`250ms~500ms`
  - 动画页（启动、升级）：`100ms~200ms`
- 软键提示栏：仅在页面切换或焦点变化时重绘。
- 若 `g_bDispPageDirty = true`：整页重建。
- 若仅局部数值变化：优先局部重绘，减少闪烁。

## 9. 异常与优先级规则
- `错误页 > 升级页 > 关机页 > 工作页 > 设置页`
- 传感器失联时：状态栏显示 `!`，并在 `P13_ALARM` 给出文字说明。
- 严重异常时：
  - 首页保留核心状态；
  - 同时允许自动跳告警页；
  - 蜂鸣器按现有策略提示。
- 当前实现中，错误覆盖解除后默认优先返回来源工作页，再回退到 `HOME`。

## 10. 推荐落地顺序
1. 先实现 `P01_BOOTING / P10_HOME / P13_ALARM / P20_UPGRADE / P21_CLOSING`。
2. 再实现 `P11_ENV / P12_ACT / P14_SETTING`。
3. 最后补充图标库、动画和局部刷新优化。

## 11. 交付文件说明
- `APP_UI_布局总览.csv`：像 Excel 总览图，适合先看全貌。

- `APP_UI_运行细则.csv`：逐条列出状态机、按键、超时、异常处理规则。
